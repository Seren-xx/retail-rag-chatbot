# retail-rag-chatbot
> 基于 RAG（检索增强生成）技术构建的智能客服系统，实现多格式知识接入、语义检索，支持商品咨询、推荐及售后问答等场景。

## 项目背景

针对传统客服系统无法利用私有知识库、回答不准确的问题，本项目构建了一套完整的 RAG 智能客服解决方案。系统支持商品知识文档的自动解析、智能检索和精准回答，有效解决了客服场景中的知识更新频繁、数值查询不稳定、语义理解不足等痛点。

## 核心功能

### 1. 文档解析与结构化预处理

- **段落优先+标点分句+块重叠策略**：解决固定长度切分造成的语义断裂问题
- **多维元数据增强**：自动为文本块添加来源、类别、内容类型等元数据，支持检索过滤
- **表格特征检测**：自动识别包含价格、折扣等数值信息的文档片段
- **多格式支持**：支持 TXT等多种格式文件上传及手动输入知识内容

### 2. 检索优化

- **混合检索**：向量语义检索 + BM25 关键词检索双路召回
- **RRF 融合算法**：Reciprocal Rank Fusion 融合多路检索结果，平衡精准与语义理解
- **CrossEncoder 重排**：使用交叉编码器对候选结果进行精细化排序，降低干扰信息
- **LLM 元数据提取**：自动从用户查询中提取类别、品牌、价格范围等过滤条件，约束检索范围

### 3. 商品知识增量更新

- **三级去重机制**：
  - **MD5 精确匹配**：快速过滤完全重复内容
  - **SimHash 近似匹配**：基于汉明距离检测相似内容
  - **向量语义去重**：基于余弦相似度检测语义重复
- **时间戳元数据**：记录每条知识的创建时间
- **自动过期淘汰**：根据配置的过期天数自动清理过期数据，实现低成本准实时同步

### 4. 表格数值精确查询

- **意图规则分流**：自动识别数值查询意图（价格、折扣、库存等）
- **双通路架构**：
  - **精准查询通路**：针对数值类问题，直接定位包含表格/数值信息的文档
  - **语义生成通路**：针对一般咨询问题，使用混合检索+LLM生成回答
- **数值约束提取**：自动提取价格范围、折扣比例、比较操作符等约束条件

## 项目结构

```
RAG/
├── app_qa.py                 # Streamlit 统一应用入口（问答+知识管理+系统状态）
├── rag.py                    # RAG 服务核心（检索链、意图路由）
├── vector_stores.py          # 向量存储服务（ChromaDB + 混合检索 + 去重）
├── text_splitter.py          # 高级文本分割器（段落优先+标点分句+块重叠）
├── deduplication.py          # 三级去重系统（MD5 + SimHash + 向量语义）
├── hybrid_retriever.py       # 混合检索器（向量 + BM25 + RRF + CrossEncoder）
├── intent_router.py          # 意图路由（数值查询识别 + 元数据提取）
├── file_history_store.py     # 对话历史持久化存储
├── config_data.py            # 全局配置文件
└── README.md                 # 项目说明文档
```

## 快速开始

### 环境要求

- Python
- pip 包管理器

### 安装依赖

```bash
pip install streamlit langchain langchain-chroma langchain-community
pip install sentence-transformers chromadb
```

### 配置 API Key

本项目使用阿里云 DashScope 服务，需要配置 API Key：

```bash
# Windows PowerShell
$env:DASHSCOPE_API_KEY="your-api-key-here"

# Linux/Mac
export DASHSCOPE_API_KEY="your-api-key-here"
```

### 启动应用

```bash
streamlit run app_qa.py
```

## 使用指南

### 智能问答

1. 在侧边栏选择「智能问答」
2. 在输入框输入您的问题，例如：
   - "我体重90斤，推荐穿什么尺码？"
   - "这款商品多少钱？"
   - "有什么洗涤注意事项？"
3. 系统会自动识别意图并返回精准回答

### 知识库管理

1. 在侧边栏选择「知识库管理」
2. 上传 TXT 等多种格式的知识文档，或手动输入知识内容
3. 系统自动进行文本分割、去重、向量化并入库

### 系统状态

查看当前知识库文档数量、嵌入模型配置、检索参数等系统信息。

## 配置说明

在 `config_data.py` 中可调整以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `chunk_size` | 500 | 文本块大小 |
| `chunk_overlap` | 80 | 文本块重叠字符数 |
| `vector_top_k` | 10 | 向量检索返回数量 |
| `bm25_top_k` | 10 | BM25 检索返回数量 |
| `rrf_k` | 60 | RRF 融合常数 |
| `final_top_k` | 5 | 最终返回文档数 |
| `reranker_top_k` | 10 | CrossEncoder 重排候选数 |
| `simhash_threshold` | 3 | SimHash 汉明距离阈值 |
| `vector_simhash_threshold` | 0.85 | 向量语义相似度阈值 |
| `data_expire_days` | 90 | 数据过期天数 |

## 技术亮点

### 1. 语义感知的文本分割

传统的固定长度切分会破坏语义完整性。本系统采用**段落优先 → 标点分句 → 块重叠**的三级分割策略，确保每个文本块保持语义完整，同时通过重叠机制保留上下文关联。

### 2. 多路召回 + 智能排序

单一检索方式难以兼顾精准率和召回率。系统同时使用向量语义检索和 BM25 关键词检索，通过 RRF 算法融合结果，再使用 CrossEncoder 进行精细化重排，显著提升检索质量。

### 3. 三级去重保障数据质量

商品知识频繁更新容易导致数据冗余。系统通过 MD5 精确匹配、SimHash 近似匹配、向量语义相似度三级去重，确保知识库中只保留差异化内容，降低存储成本。

### 4. 意图驱动的双通路架构

数值类查询（价格、折扣等）和语义类查询（推荐、咨询等）采用不同的处理通路。系统自动识别用户意图，数值查询走精准匹配通路，语义查询走混合检索通路，有效降低数值推理误差。
